# 🛍️ Loja Digital

Uma interface de **loja digital** desenvolvida para praticar e aprimorar conhecimentos em desenvolvimento Front-end.

##  Sobre o projeto

O projeto apresenta uma experiência de navegação para uma loja virtual, com diferentes páginas e uma estrutura organizada para separar conteúdos, estilos e recursos visuais.

A aplicação foi desenvolvida pensando em uma interface **simples, organizada e responsiva**, explorando diferentes elementos de uma página de e-commerce.

##  Destaques

* Interface de loja virtual
* Múltiplas páginas
* Estilização personalizada com CSS
* Uso e organização de imagens e outros recursos
* Estrutura pensada para diferentes tamanhos de tela
* Organização do projeto em páginas, estilos e assets

## Tecnologias

* **HTML5** — estrutura e semântica das páginas
* **CSS3** — estilização, layout e responsividade

## Objetivo

Este projeto faz parte dos meus estudos em **desenvolvimento Front-end**, com foco na prática de criação de interfaces, organização de projetos e aplicação dos fundamentos de HTML e CSS.



Projeto desenvolvido para fins de estudo e aprimoramento em desenvolvimento web.
